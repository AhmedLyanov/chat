# IThub Chat

**IThub Chat** — это студенческая чат-платформа для колледжа IThub, где студенты могут общаться, знакомиться, делиться опытом и помогать друг другу.

## О проекте

Проект реализован как современное веб-приложение на основе React и FastAPI. 
Фронтенд отображает интерфейс чата и страницу авторизации, а бэкенд управляет регистрацией и логином студентов через систему IThub.

## Возможности

- Авторизация студентов по email и паролю
- Валидация входа на фронтенде с уведомлениями об ошибках
- Легкий интерфейс списка чатов с аватарками, статусом онлайн и непрочитанными сообщениями
- Поддержка страниц: домашняя страница, вход/регистрация, профиль
- Простая структура для дальнейшего развития: чат, контакты, профиль, аутентификация

## Технологии

- Frontend:
  - React
  - React Router
  - Vite
  - Tailwind CSS
  - Lottie Web
- Backend:
  - FastAPI
  - SQLite
- Прочее:
  - ESLint
  - Поддержка CORS между `http://localhost:5173` и сервером

## Структура проекта

- `client/` — фронтенд приложение
  - `src/pages/` — страницы приложения
  - `src/widgets/` — компоненты интерфейса
- `server/` — бэкенд на FastAPI
  - `app/routes/` — маршруты API
  - `app/services/` — логика работы с пользователями и БД
  - `app/database/` — подключение и инициализация SQLite
  - `app/models/` — модели данных
- `instance/` — база данных SQLite

## Установка и запуск

### 1. Установка зависимостей фронтенда

```bash
cd client
npm install
```

### 2. Установка зависимостей бэкенда

```bash
cd ../server
python3 -m venv venv
source venv/bin/activate
pip install fastapi uvicorn
```

> Если у вас уже есть файлы зависимостей, можно установить их из `requirements.txt`, если он будет добавлен.

### 3. Запуск сервера

```bash
cd server
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Сервер будет доступен на `http://127.0.0.1:8000`.

### 4. Запуск фронтенда

```bash
cd ../client
npm run dev
```

Фронтенд запускается на `http://localhost:5173`.

## Как использовать

1. Откройте `http://localhost:5173`
2. Перейдите на страницу авторизации
3. Введите email и пароль
4. После успешного входа вы попадете на домашнюю страницу с чатом

## Особенности реализации

- `server/app/database/connections.py` создаёт таблицу `users` в базе данных `instance/messenger.db`
- `server/app/routes/auth.py` обрабатывает POST-запросы на `/login`
- `client/src/pages/AuthPage.jsx` отправляет данные на `http://127.0.0.1:8000/login`
- `client/src/pages/HomePage.jsx` отображает список текущих чатов с простыми аватарками и статусами
